How this site was built

This portfolio was scaffolded and iterated with Claude Code using the same AI development workflow I pioneered at EarnIn. The AI tools, tech stack, and specific engineering decisions are all documented here.

Stack
Astro Framework

Zero client-side JS by default. Pages pre-render at build time: no hydration, no bundle to ship.

TypeScript Language

Typed interfaces for every content type: Project, Job, Role, SkillGroup. Schema changes fail at build, not at runtime.

CSS Custom Properties Design system

Hand-rolled design token layer: --bg, --surface, --text, --accent, --border, --shadow, --radius. No CSS-in-JS, no Tailwind config. One file, one source of truth.

GitHub Actions CI/CD

Push to main, get a deploy. Astro build runs in CI; broken builds don't ship.

GitHub Pages Hosting

Static hosting from the repo. No server, no cold starts, no infra to manage.

Design decisions

OS-native dark mode

OS preference sets the initial theme via an inline script before first paint, preventing any flash. Toggling writes to sessionStorage so the choice persists across page navigations within the same tab. Closing the tab clears sessionStorage and the OS preference takes over again on the next visit.

WCAG AA contrast

--text-muted tuned from #756f68 (4.39:1, failing) to #6b6460 (5.16:1, passing) against the light background at small text sizes.

Reduced motion

prefers-reduced-motion disables blur/translate fade-ins, orb animations, and the pulsing dot. Transitions fall back to opacity only.

Concentric border radii

Nested surfaces: outer radius = inner radius + padding. Mismatched radii on parent/child elements is the most common thing that makes interfaces feel cheap.

Scale on press

scale: 0.96 on :active for all interactive elements. 0.96 is the ceiling; anything below 0.95 reads as exaggerated on desktop.

Transition specificity

No transition: all. Every transition lists exact properties (background-color, border-color, scale) so layout changes are never accidentally animated.

Focus visibility

:focus-visible, not :focus. Keyboard users get a visible ring; mouse users don't. Two different interaction modes, two different states.

Staggered hero

transition-delay set per element (0 / 100 / 200 / 300ms), not on a wrapper. Each semantic chunk animates independently so individual delays are meaningful.
